# 🎮 Game Reviews Website

A dynamic web application that displays free-to-play games using the **FreeToGame API**, allowing users to browse games by category and view detailed information in a modern and interactive UI.

---

## 📌 Features

- 🔍 Browse games by category (MMORPG, Shooter, MOBA, Anime, etc.)
- 🎠 Dynamic header carousel that updates based on selected category
- 🖼️ Game cards with hover effects and smooth animations
- 🧾 Game details displayed inside a Bootstrap modal
- ⏳ Loading spinner while fetching data
- 📱 Fully responsive design (Desktop & Mobile)
- 🌐 Real API integration with CORS handling using AllOrigins proxy

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **Bootstrap 5**
- **JavaScript (ES6)**
- **FreeToGame API**
- **AllOrigins CORS Proxy**
